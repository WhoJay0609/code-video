# 按题材编排画面

选择当前题材的一种主视觉语言，再按内容加入必要的其他机制。以下是对多种动画工作流的原创归纳；来源与采用记录见 [source-notes.md](source-notes.md)。

## 动作与阅读节奏

把预备、主要动作、结果保持和退出分成可调整的时间段。命名时间点承接旁白和关键操作；串行动作表达因果，并行动作表达关联，错开动作引导注意。先用无装饰的运动证明镜头成立，再添加阴影、笔触和粒子。

形态变换先保留物体身份，再改变轮廓或布局。遮罩揭示先确定观看顺序；镜头推进先确定下一处兴趣点。固定随机种子与时间解析扰动可以保留纹理风格，但不能替代构图。

这些方法借鉴时间轴/生成器的编排能力，不要求所有作品使用同一个库；工具选择见 [library-selection.md](library-selection.md)。

## 产品宣传与 UI 变形

产品宣传先展示用户任务，再用真实界面或明确的概念界面完成任务，最后让结果成为视觉主角。每个镜头表达一个动作或收益；文案、界面和数字交替承担主体，避免所有镜头都是标题加卡片。

UI 变形让同一个主体承接多个功能：按钮拉伸成输入框，输入框成为进度条，进度条转成结果图，再收回按钮。位置、轮廓或内部元素在变化前后保持联系。程序光标按点击、按住、拖动、松开的顺序驱动响应，状态变化有明确原因。

用尺寸、圆角、遮罩、内部排版和小幅回弹表达材质。前缘与后缘可以采用不同的弹簧响应形成拉伸；内容退出和新内容进入分开安排，确保文字可读。复用同一主体不等于每帧只能有一个 DOM 元素。

极简片使用一致字形、足够留白和有限强调色；输入、关键操作、输出的视觉节奏有差异。真实素材承担证据，动效承担组织。用户没有素材时做明确的程序化概念片。

## 科普、数学与线稿

先出现问题或可识别的物体，再让机制发生，最后显示规律或结果。例如 attention 讲解可以让 token 建立关系、显示权重差别、聚合信息，最后解释输出；不能仅把模块名称依次淡入。

颜色绑定语义并贯穿全片。箭头、路径、高亮和运动表达因果，注释靠近被解释对象。公式和量纲保持正确，讲解中的简化明确对应当前可视化，不把演示数据写成实验结论。

数据动画保留数据项身份，让排序、数值和位置变化对应真实关系。解析信号同时绘制组成项与结果，用一个采样位置展示它们如何组合，再切换表示方式。不能让不同坐标范围造成幅度、速度或比例的错误暗示。

线稿通过路径分段揭示和固定的轻微笔触扰动形成手绘感。笔触扰动从路径索引计算，确保暂停或回退后画面稳定。把幽默放在角色和动作里，保留清晰主体与节奏。

如果有旁白，按句子和强调词安排画面；双语字幕预留独立区域，不把两种语言塞进图解。

## 动态字体与作品集

文字是运动主体：字形放大成为遮罩、关键词转成形状、字组随镜头换尺度，或沿路径组织空间。将字体、几何、负空间和色块编排成有变化的短片。

先建立一个视觉动机，再让它变形和回归。对快、慢、静止和爆发安排明确差异；运动后让重要字词停留可读。强节奏可以来自切换、遮罩、缩放和对齐，不必堆叠效果。

开场和收束承担记忆点；中间至少一次改变构图或观看尺度。若是作品集，风格实验与共同的视觉动机并存。

## 多尺度连续推镜

明确各尺度的中心、进入对象、下一个场景和出现时间。进入芯片、细胞、原子等尺度时，用共用轮廓、纹理或结构做视觉匹配；镜头速度在可读段落放慢。

很大的尺度差异可在视觉对齐处换场，用对数尺度或分段相机曲线避免突然加速。每一层拥有独立细节等级，进入后揭示新信息，远景则简化细节。

需要真实尺度时核实标签与数量级；作为视觉隐喻时用文案明确意义。让观众知道当前身处哪一层。

## 像素角色与循环

在低分辨率离屏画布绘制，用整数倍率显示，关闭插值。逻辑坐标、线宽和最终色彩量化，轮廓先于细节。有限色板组织明暗，避免缩小后的矢量图冒充像素美术。

角色动作包含预备、主要动作、冲击和恢复。姿态、道具角度、重心和粒子位置从相位与时间计算；可以按 8–12 fps 量化角色动作，同时保持页面播放顺畅。选择状态机或解析时间段取决于作品是否要任意定位；使用本技能的截图工具时须支持任意定位。

只在动作需要时加入冲击与粒子，留出干净剪影。无缝循环要让恢复段回到相同姿态与速度，随机闪烁和粒子也要周期一致。

## 程序化 3D 与电影镜头

先解决主角、镜头路径、灯光和剪影，再增加环境细节。材质、雾、阴影和层次共同建立空间；重复植被或角色用实例化等现有能力控制成本。

角色或机械动作来自关节、路径或约束，镜头跟随明确兴趣点。走路与移动速度匹配，脚接触地面时保持接触。模拟依赖历史状态时，用可复现缓存或固定步进重建，不能让随机拖动时间造成不同结果。

对短片，先排好自动镜头与时间线；用户要求交互时再提供旋转、跟随、时间或环境控制。交互场景在播放模式中仍要有可以直接观看的路径。

在实际浏览器检查透明排序、裁剪、阴影、接地与遮挡。草稿先降低像素数和后期效果，核心镜头成立后再增加最终细节。

角色动作可分为持续姿态与一次性强调动作，并用可控权重衔接。视频定位时重新求这些权重与启用状态；实时状态机的“上一次做了什么”不能成为拖动后的隐藏输入。

## 从创意到可改的场景

将场景边界、文案、配色和关键时间集中在可找到的位置。修改单个镜头时保留其他镜头的入口和出口关系。片长改变后重新检查阅读时间、声画同步和结尾，不只缩放全部时间。
